# 共用播放器模板：legacy-v7

此模板依据用户指定的旧版 `christmas-canon` 网站提取，统一字体、面板材质、排版、4×8 点阵乐谱、播放高亮、逐拍导航和舞台。歌曲只提供数字谱；主题由独立注册表提供，组合清单仅引用初始主题 ID；不同主题不复制页面，也不另写一套编辑/播放逻辑。

## 模板的固定部分

- `app/index.html`：音乐库与唯一播放器结构。播放器为顶部标题、播放控制、左侧卷帘/15键、右侧逐拍谱/舞台或编辑台。
- `app/styles.css`：旧版比例、字号层级、近方形节拍格及装饰层；宽窗口双栏，窄窗口纵向排布。
- `src/38-player-template.js`：应用 `config/themes/` 的配置、颜色数据白名单和统一入口 `applyPlayerTemplate(project, host)`。
- `src/40-ui.js`：逐拍渲染、高亮、余音、翻页及共享导航，统一供全部主题调用。
- `src/20-audio.js`：音频时钟和延音；舞台动画移至独立的 `src/37-theme-scenes.js`；保留旧网站的 iOS playback audio session 兼容逻辑。
- `src/47-edit-session.js`：只读/编辑/保存会话。默认只读、修改前隔离副本等新版交互继续共用。

常用字号：计时 20px（紧凑窗口 18px）、琴键编号/音名 13px、面板标题 18px（低高度窗口 16px）、节拍序号 10px、音名 9px。点阵保持 5×3 键位，逐拍谱每页 4×8，当前格金色/主题色边框及外发光、休止格弱化、单音/双音/多音分色。播放时可显示余音和经过格淡光，暂停时清除这些播放反馈。

卷帘行底色直接使用用户提供 v7 源码的逐行分布。8、10、12、20 秒窗口均显示每秒六格的细分格线。

点击格子、上一页/下一页和上个/下个节拍会暂停并定位；键盘左右键移动一个实际事件。播放自动跟随当前事件翻页。不同长度、不同调性的乐曲使用相同规则。

## 更换或增加主题

现有圣诞、星光和暮光已调用同一模板。通过编辑模式中的「场景设计」选择主题，可设置主题色、背景色、飘雪、光晕、动作与专属舞台图。配置可导出为 `.skytheme`，再应用于其他乐曲。

若只想制作一个新配色，不需要新增页面或修改 JavaScript：在主题包的 `scene.json` 中使用已支持的基础 `id`（如 `starlight`），并添加 `appearance` 配色字段。例如：

```json
{
  "id": "starlight",
  "name": "海边月夜",
  "accent": "#a8ddd9",
  "backgroundColor": "#102e39",
  "snow": 12,
  "glow": 40,
  "motion": "ambient",
  "appearance": {
    "surfaceStart": "#183e48",
    "surfaceEnd": "#102b36",
    "controlStart": "#1a424b",
    "controlEnd": "#17303f",
    "button": "#204651",
    "hover": "#325c68",
    "border": "#5c8790",
    "gridStart": "#244b53",
    "gridEnd": "#15333e",
    "rest": "#102b33",
    "dot": "#527982",
    "note": "#d3f1e6",
    "chord": "#f2dbb4",
    "poly": "#eab7c1",
    "activeStart": "#486e73",
    "activeEnd": "#669694"
  }
}
```

与 `manifest.json`（`format: "skytheme"`、`schemaVersion: 1`）一起打包即可。未提供的颜色从基础主题继承。颜色仅接受 `#RRGGBB`；不会把主题包中的字符串当作 CSS 规则或脚本执行。额外舞台图沿用 `.skytheme` 的 `image` 和资源文件机制。

已有可直接导入的 [海边月夜示例](../samples/moonlight-template.skytheme)，可复制配置作为下一套主题的起点。

完整配色键以 `PLAYER_APPEARANCE.christmas` 为准，涵盖面板、控制条、按钮、文字、点阵、休止格、高亮和舞台。`accent` 和 `backgroundColor` 优先于对应配色键。归一化会保留合法的 `appearance`，保存、重开、主题导出和项目导出均沿用这份配置。

若要增加内置的独立主题分类，在 `00-core.js` 的 `PRESETS` 与 `38-player-template.js` 的 `PLAYER_APPEARANCE` 中添加同一个主题 ID，并在场景选择器中登记；无需复制播放器 DOM、样式布局或交互处理器。新增具体装饰时应放在既有舞台装饰层内，不改变音乐模块尺寸。

## 装饰、舞台和验证

圣诞树 `app/assets/christmas/legacy-tree.png` 从用户现有旧站文件中原样提取，未改变图像；原 48 个素材保留。雪花和树在构建独立 HTML 时嵌入，不依赖相对 URL。舞台 canvas 使用固定容器并在下一帧读取布局，避免点阵撑开面板前的尺寸造成角色裁切。装饰层不接收点击；减少动态效果设置或动作关闭时停止粒子及灯光动画。

使用 `tests/legacy_layout.py --output <新的验证目录>` 检查六种窗口的点阵比例、播放高亮/余音、翻页和编辑；使用 `tests/player_template.py --output <新的验证目录>` 检查主题切换不改变结构、配色覆盖往返和舞台尺寸。运行需要 Playwright 和本机 Edge。原 v0.4 原始基线、截图与导入清单仍保留在外层版本目录。

## 旧版布局精确校对（2026-11-06）

以用户指定的《卡农圣诞夜_圣诞互动乐谱_v7_独立版.html》源码为准（SHA-256：`83689830f1efcaaa074831d14772a058842c04a4c936078d542d0a8d5ed165f5`；三段 CSS 与原站提交 `3a8ed07` 一致），在 1366×768、1920×1080 下逐项采集浏览器实际尺寸和计算样式：恢复 normal 行高、面板原始内边距、标题/说明间距、键盘 6px 间距和原始键高；右侧逐拍谱与舞台恢复同一连续面板。节拍格恢复旧版精确边框、休止文字、金色描边与阴影。保留 12 大调、显式编辑与保存等新增控件；新增功能的控件数量与旧站不同，但其基础排版遵循同一体系。窄屏继续使用纵向布局。

卷帘音块采用略小的圆角矩形与轻微阴影；绘制时为相邻同音预留细缝。只调整视觉尺寸，实际音符时间、时值和发声逻辑不变。

卷帘使用旧版三色：浅 `#244438`、较深 `#112e29`、深 `#0b2825`，按 v7 原绘制条件排列（1、8、15 号音行浅色，其余行按原行序交替）。音名字号仍按行高限制在 9–11px，垂直居中。所有窗口的细分格线都在行底色之后绘制。

## 卷帘扫描与谱面进度

谱面进度条使用金色长条滑块，轨道前后保持同一底色，不显示已播放区间的金色填充；键盘和拖动定位继续使用原生范围控件。

卷帘按所选 8/10/12/20 秒窗口逐页显示。扫描条从左向右行进，上下端均有圆球，到末尾切换下一页。下方「谱面进度」定位音乐并保持扫描条的横向位置，通过调整页起点让音符与音乐继续对齐；顶部全曲进度条仍按歌曲时间定位到对应的标准页。暂停冻结扫描，切换窗口保持横向比例。末页按剩余有效时长铺满卷帘，不补齐到整段窗口；音符和扫描条使用同一时间比例，音乐结束时扫描条到达最右边并保留最终谱面，不翻空白页。重新播放或定位会取消曲尾扫描。

## 自动清理曲尾空白

加载曲库、导入和确认保存时，会移除最后一个有音符事件之后连续的空白节拍，同步缩短歌曲时长、卷帘进度范围和逐拍格数。开头及曲中的休止、全部有音符事件的时间与时值保持不变，结束时间至少覆盖所有保留音符的完整时值。即使尾部没有显式空白事件，也去掉最后有效音符结束之后多余的空白时长。编辑中的临时空白格保留到保存时再清理，便于继续添加音符；整首尚未填写音符的新建模板保留，避免失去编辑入口。原始内置资源、示例文件和历史基线不改写，此规则在应用加载时统一处理。

定位到曲尾时也保留含音符的最终视图；末页从普通播放、顶部进度、卷帘进度、节拍导航等入口进入时均按真实结束时间绘制。卷帘进度跳转到曲尾之前仍保持扫描条横向比例，直接跳至音乐终点则显示最终谱面和最右端扫描条。

逐拍乐谱末页始终补齐 8×4 共 32 个格位，不足部分是不可聚焦、不可点击且不计入事件/页数的弱化占位格；占位不写入曲谱，不增加时长，翻页前后面板高度保持一致。

## 音域选择

原「大调」控件展示名为「音域」，沿用已有 12 大调转调及存储值。金色当前值按钮打开向左延伸、一次显示 5 个预选的横向选项条，鼠标悬停时滚轮左右移动选项，选中项保持 v7 金色样式，悬停/键盘焦点有反馈，确认选择后收回。窄屏使用可水平滚动的同一选项条并限制在屏幕内，不使用向下展开的原生菜单；点击外侧、Escape、滚动离开或返回音乐库时关闭。键盘左右键、Home/End 和 Enter/Space 可完成选择。

音域选项采用固定 44px 格宽、5px 格距，中间五格加两侧各 16px 渐隐区。外层无背景外框，格子进入两侧时保持原色，直接逐渐透明消失，不叠加黑色或变暗效果。滚轮按小幅距离累积目标并逐帧平滑接近，单次输入最多移动半格，不整页跳转；关闭或选择时停止滚动动画。

## 音色弹层

音色按钮使用同一播放器主题，基准框固定在原按钮位置，向上和向下最多各展开两个选项，列表围绕固定框小幅平滑移动。选择首项时框上方不补空白，选择末项时框下方不补空白；点击任一选项确认并收回。它与音域选项共用 `bindSmoothWheel()`，分别采用纵向/横向的小幅平滑移动；展开两个选择器时会相互收起。数据与来源见 [音色及光遇基准](INSTRUMENTS_AND_SKY.md)。

音色列表滚动停止后平滑对齐完整格；基准框在动画和首末边界收缩时都与原按钮的 x/y/宽/高一致，整个面板不占布局空间。

## 音量交互和 UI 识别

所有歌曲、音色和主题共用 `volumeSlider`（原生 slider，可访问名称“音量”、`data-control="volume"`）与 `volumeValue`（百分比输出）。0–100%，0 为静音；方向键微调、Home/End 到边界。规则集中在 `config/player-interactions.json` 的 `volume`，绑定归 `src/39-player-interactions.js`。样式使用当前主题颜色；窄屏同播放栏换行。

音量保存于每首歌的 `playback.volume`（0–1），随完整 `.skymusic` 保存；纯谱 `.skytrack` 不携带音量。缺省改为 25%，已有歌曲主动保存的音量值继续保留。音量与延音滑块共用 `var(--gold)` 配色及相同的百分比文字色。

默认位置与输出增益是两项独立配置：`volume.default = 0.25` 只控制新歌曲/缺省设置的初始滑块位置；`volume.maxGain = 8` 独立定义提高后的整体输出范围。实际增益始终是 `滑块百分比 / 100 × maxGain`，25% 仅表示最大输出的四分之一，不作为参照值或归一化分母。以后修改默认百分比不改变音量曲线和最大输出。

滑块 0 为静音，100% 为完整输出范围，中间按比例连续变化，界面以 1% 微调；输出增益比不等于主观响度比。压缩器后统一控制干声、延音混响和试听，25ms 平滑过渡，不暂停播放。

卷帘时间轴：8s/10s 窗口每 1 秒标注，12s/20s 每 5 秒标注，配置归 `roll.labelIntervalSecondsByWindow`。每秒竖线及细分格保留；最终音符附近补充可见范围内最近的整秒标签（无整秒时显示精确时间），必要时让相邻常规标签避让。文字中心与对应竖线共用同一横坐标，右侧留足文字空间，最终谱面不增加空白时长。
