# 首页交互契约

平台首页独立于六款单曲主题。共享结构在 `app/index.html`，样式在 `app/styles.css`，控制器为 `src/41-home-experience.js`，纯参数在 `config/home-interactions.json`。歌曲卡片仍由 `40-ui.js` 读取原曲库生成，不复制播放器或主题处理器。

## 尺寸与展示

桌面三列卡片占满各自网格列，保留原有卡片高度计算和两行展示；光锥是材质和交互效果，不是窄长卡片比例。内容区最大1160px，两侧留白；中等桌面至少32px，手机20px。中文收藏标题在上，英文在下。曲目不足六首时展示真实数量，不伪造歌曲填位。

顶部横幅展示六款内置主题，左侧插图向右渐隐，右侧透出平台大背景。六个白点在横幅框内底部居中，当前项放大提亮。左右箭头为全高识别区，背景为低透明白色向透明渐变，横幅边缘有克制白光。收藏标题与右侧工具相对卡片外边界各内缩12px；横幅与标题至少相隔28px。

## 轮播

默认停留6000ms，680ms向左过渡，首尾使用两个不可访问的克隆片连续衔接。自动轮播不改变歌曲主题或音乐状态。鼠标悬停、键盘焦点进入、页面隐藏或进入单曲时暂停；手动点击圆点、箭头和左右方向键均可选择。只对手动选择播报主题名称。连续输入保留最后目标和方向。

## 卡片

点击卡面翻到无图片的信息背面，再点返回；背面只显示音符数、音域、作者三个字段，保留歌曲标题。播放、收藏、重命名、复制、删除按钮独立操作，不触发翻面。按Enter/空格可翻面，可访问名称及正反面隐藏状态同步更新。翻面是内存视图状态，不写入项目。

倾斜由鼠标相对未变形卡片的位置驱动，目标最大6°，使用质量1、刚度170、阻尼25的弹簧缓动；速度和步长均限幅，离开后回正。插图层与微光层反向视差，光学膜的虹彩、反射角与高光位置由同一视角驱动；悬停抬升4px，不使用随机摇晃。翻面820ms分为起转、侧立、背面显现与2°收势，快速反向输入从当前矩阵接续，减少动态效果时直接切换。装饰框和操作按钮在转身途中暂隐，避免出现漂浮框线。卡面和内层翻面分别处理，翻转结束后播放及操作按钮恢复独立可点击层。

触屏只翻面，不模拟悬停倾斜。系统减少动态效果时停止自动轮播、倾斜、过渡及背景流动，保留手动选择和翻面。背景图保持稳定；完整视口叠加域扭曲分形噪声光雾，以不同方向的缓慢局部涡流替代整条扫描光带。最长边240px的离屏纹理以16fps生成后柔化放大；手机长边同样限幅，隐藏页面/进入播放器停止动画。光雾层不接收指针事件。

## 主题预览与设置

每个真实轮播页自带“设置主题”按钮，随页移动；克隆页不可交互。按钮打开独立预览窗口，显示该主题场景、15行卷帘配色和15键材质。名称、背景色、高亮色、辉光及动态开关只改变临时主题副本。恢复预设不写曲库；导出复用既有 `.skytheme` 资源打包器，包含资源并给修改版独立ID。用户仍需通过平台录入新主题才能供歌曲调用。这里不切换首页背景，不设置新歌曲默认值，不更改已有歌曲。

动画设计参考入口为官方[《浮光映影：拂晓之前》](https://www.bilibili.com/video/BV1qz4y187rB/)。视频播放读取受限，本次采用分层视差、虹彩反射和分段翻转的自主实现，未声称逐帧复刻，也未复制游戏素材。

## 生命周期与验证

进入单曲停止首页计时与动画；刷新和导航基准重置时清空临时翻面、倾斜和轮播页码，不改曲库键、谱面、音量、播放器编辑状态。复用已有平台插图与主题素材，不引用外部游戏资产。

运行 `tests/home_experience.py --output <新目录>` 检查六主题循环及边界、暂停恢复、阻尼范围、真实翻转中间态及全部操作、播放归零、四种桌面尺寸、框内圆点、留白、触屏、减少动态效果、对称内缩、局部光雾变化和六主题预览/修改/导出隔离。可用 `--url <网址>` 验证发布版本。主题/导航隔离另由 `theme_system.py`、`config_separation.py`、`startup_navigation.py` 回归。
