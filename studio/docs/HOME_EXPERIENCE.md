# 首页交互契约

平台首页独立于六款单曲主题。共享结构在 `app/index.html`，样式在 `app/styles.css`，控制器为 `src/41-home-experience.js`，纯参数在 `config/home-interactions.json`。歌曲卡片仍由 `40-ui.js` 读取原曲库生成，不复制播放器或主题处理器。

## 尺寸与展示

桌面三列卡片占满各自网格列，保留原有卡片高度计算和两行展示；光锥是材质和交互效果，不是窄长卡片比例。内容区最大1160px，两侧留白；中等桌面至少32px，手机20px。中文收藏标题在上，英文在下。曲目不足六首时展示真实数量，不伪造歌曲填位。

顶部横幅展示六款内置主题，左侧插图向右渐隐，右侧透出平台大背景。六个白点在横幅框内底部居中，当前项放大提亮。左右箭头为全高识别区；不把主题图片或装饰当作按钮。

## 轮播

默认停留6000ms，680ms向左过渡，首尾使用两个不可访问的克隆片连续衔接。自动轮播不改变歌曲主题或音乐状态。鼠标悬停、键盘焦点进入、页面隐藏或进入单曲时暂停；手动点击圆点、箭头和左右方向键均可选择。只对手动选择播报主题名称。连续输入保留最后目标和方向。

## 卡片

点击卡面翻到无图片的信息背面，再点返回；背面显示时长、音符数、事件数、音域、作者、来源和简介。播放、收藏、重命名、复制、删除按钮独立操作，不触发翻面。按Enter/空格可翻面，可访问名称及正反面隐藏状态同步更新。翻面是内存视图状态，不写入项目。

倾斜由鼠标相对未变形卡片的位置驱动，目标最大5°，使用质量1、刚度135、阻尼20的弹簧缓动；速度和步长均限幅，离开后回正。反光追随同一指针并衰减，不使用随机摇晃。卡面和内层翻面分别处理，播放及操作按钮始终处于可点击层。

触屏只翻面，不模拟悬停倾斜。系统减少动态效果时停止自动轮播、倾斜、过渡及背景流动，保留手动选择和翻面。背景图、两层呼吸光晕及上下流风覆盖完整视口，均不接收指针事件。

## 生命周期与验证

进入单曲停止首页计时与动画；刷新和导航基准重置时清空临时翻面、倾斜和轮播页码，不改曲库键、谱面、音量、播放器编辑状态。复用已有平台插图与主题素材，不引用外部游戏资产。

运行 `tests/home_experience.py --output <新目录>` 检查六主题循环及边界、暂停恢复、阻尼范围、翻面及全部操作、播放归零、四种桌面尺寸、框内圆点、留白、触屏和减少动态效果。可用 `--url <网址>` 验证发布版本。主题/导航隔离另由 `theme_system.py`、`config_separation.py`、`startup_navigation.py` 回归。
