# Sky Music Studio · 重新设计后的架构与阶段验收

## 不再在 v7 单文件上直接补丁

此前多次迭代的核心风险是：乐谱数据、定时器、音源、舞台动画和画面 DOM 写在同一段 JS 中，任何修改可能使其他模块静默失效。新工程将 **v7 确定的视觉比例** 与 **谱面数据** 解耦。

### 依赖关系

音乐库启动 → 项目规范化与检验 → 主题预设（CSS token+场景资源） → 钢琴卷帘/逐拍格/15键校对

独立的音频引擎基于同一份时间轴调度；场景只读取「播放中」及「声音活动」状态，不反过来决定演奏时间。

### 源文件模块

- `00-core.js`: 项目归一化、歌曲库、音名映射和UI共用状态。
- `10-zip.js`: 无外部依赖的 `.skymusic` 打包/校验/导入。
- `20-audio.js`: Web Audio 采样解码、调度器、进度时钟、舞台动画。
- `30-import.js`: JSON/CSV/MIDI 导入、实验性单音频率检测。视频识别是下一阶段。
- `40-ui.js`: 开始界面、15轨卷帘、逐拍格、键盘面板、主题切换。
- `99-bootstrap.js`: 控件绑定与程序启动。

交付版把模块编译进经典 JS，避免浏览器通过本地 `file://` 打开时 ES module 的 CORS 问题。

## 关键不变量

1. 始终以 v7 已验证的 15 轨、15键布局、32格分页为参照，主题只换视觉资源与 token。
2. 原始 v7 的1296格不因为看见「休止」就删掉；休止也占时间格。
3. 播放位置来自同一个 Web Audio 时钟，不允许音源计时和动画计时分别推进歌曲。
4. 一份项目文件只含数据和资源，不执行作者提供的任何 JS、HTML。
5. 清楚标注 `confidence=unverified`、转录限制和必要人工校对。
6. 自动转录数据不会默认为「精确乐谱」。

## 下一轮优先修复

- 做可视化节奏编辑（改变音长、力度、拍号）和撤销/重做。
- 自定义场景 `.skytheme`，作品与皮肤可单独复用，并进行资源完整性检查。
- 在 Windows Chrome/Edge 实机进一步检查声音与场景性能。
