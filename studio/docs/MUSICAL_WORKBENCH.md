# 乐理编曲工作台

单曲播放页保留原有卷帘、逐拍乐谱、15键音高校对与主题布局；点击“曲谱编辑”才进入独立全屏乐理工作台。旧 v0.4 交付及其说明保持历史含义，不重标版本。

## 使用

首页新建时确认 BPM、拍号、网格、写入时值、Gate 和调性。原播放页只读；点击曲谱编辑进入独立全屏副本。保存或放弃后返回原播放页，恢复进入编辑前的扫描进度和谱面位置。完整谱面的原始音高、多轨及独立时值保留；原15键图样仅为显示投影，实际播放采用完整音符调度。关闭必须保存、另存为或放弃；另存为后显示导出选择。网格控制移动和吸附，写入时值控制新音长度，Gate 控制发声比例，延音控制释放。改变调性仅改变解释与音名；移调是独立命令。

左侧管理音轨、音色、音量、静音和独奏。中央支持单音、和弦内单音、多选、框选、移动和拉长；右侧修改音高、音乐位置、时值、Gate、力度。下方逐拍展示、数字谱输入、力度和光遇适配分别工作。音高缩放、时间缩放和适配音域只改变视图。

步骤输入把重叠按住的键合成和弦，全部释放后前进一步。节拍录制仅吸附起音，自由录制保留实际演奏时间。时长量化需另选。插入后移目标轨后续内容；覆写仅替换录制区间，跨边界音符保留区间外片段。键盘映射支持15个物理键槽、任意MIDI音高和八度偏移；鼠标可输入黑白键。

节奏数字谱如 `1/8 [1+3+5]/4 0/8 #4/8. 5/8t`，分别表示八分音符、四分和弦、休止、附点和三连音。先预览后提交，错误整段拒绝。小节循环终点为右侧小节边界。6/8等复拍子节拍器按附点四分分组，BPM始终表示四分音符每分钟。

## 数据与模块

960 PPQ，允许小数Tick。每音有稳定ID、轨道、绝对MIDI音高、起点、记谱长度、发声长度、Gate和力度。tempoMap与meterMap共用双向时间换算；拍号变化必须在小节边界。88键默认范围可扩展到完整MIDI范围。

- 50-music-model.js：模型、时钟、旧谱转换、数字谱、适配分析。
- 51-music-formats.js：MIDI和MusicXML读取、多轨MIDI输出。
- 52-music-audio.js：共用时钟、每轨音源和混音、节拍器、清音。
- 53-music-workbench.js：统一只读/编辑视图、虚拟化卷帘。
- 54-music-commands.js：原子编辑、撤销、选择、参数与导出命令。
- 55-music-input.js：鼠标手势和三种录制。
- 56-music-integration.js：库迁移、格式路由、创建及保存。

.skytrack v2保存完整谱面；.skymusic v3内嵌谱面及卡片，引用已录入主题。skytheme只控制外观和素材。旧score投影仅用于兼容，不是完整谱的权威来源。新schemas位于schemas/。

原曲无速度信息时显示参考120 BPM/4/4，首次播放保持原毫秒，不量化；确认基准后才允许按拍编辑。旧和弦拆成独立音符，原始谱及调性备份保存在source。曲库存储键不变；首次改写前备份原字符串至sky-studio-projects-v03-backup-musical-v2。坏记录原样保留，损坏JSON阻止覆盖。

## 格式边界与人工验收

MIDI支持PPQ格式0/1，保留轨道、通道、音高、力度、速度、拍号、程序及原文件；SMPTE和格式2明确拒绝。导出受15个旋律通道加打击乐通道限制，超限明确报错。控制器和轨内程序变化保留在来源，但试听以轨道初始音色为准。MusicXML支持partwise、声部、休止、独立时值、附点、三连音、延音连接和移调；装饰/重复等未实现语义列入报告并保留原XML，不自动展开反复。不含MusicXML导出与五线谱排版。

光遇适配必须先分析、预览并明确确认，生成独立改编曲，完整原谱保留。实时录制暂不支持循环叠录；先关闭循环。录制延迟没有自动补偿，保留音频延迟和实际按键时间用于检查。离线音源失败回退、长音听感、节拍器同步、多轨混合及真实录制延迟必须另做听音；自动断言不能替代。外接MIDI、插件、Humanize及自动BPM识别不属于本轮。
