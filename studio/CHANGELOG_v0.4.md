# Sky Music Studio v0.4 · 修改与验收记录

## 主页

- 单曲改名使用站内 `renameDialog`，支持确认与取消，不再依赖 `window.prompt()`。
- 内置身份 `builtin`，导入身份 `imported`；复制必产生新的 `user` 曲目及 ID，允许删除。删除使用站内 `deleteDialog`，不依赖 `window.confirm()`。
- 顶部主视觉区移除「导入我的谱子」「最近播放」按钮。
- 桌面首页将主视觉、标题与曲卡高度压缩至一屏，首行三个歌曲完整显示，第四张卡片与其他曲目位于下一屏可滚动区域。

## 单曲页

- 延音影响音符释放时间与合成混响湿声增益，位置改为居中对齐并显示数值。
- 新增离线钢琴 / Yamaha C5 在线两音色切换，网络故障时自动回退。
- 原来的 `sky` 调律归并到 C；同时提供12种大调。使用统一移调映射同步声音、琴键标签、卷帘标签、逐拍名称与 MIDI 导出。
- 初始只读。进入编辑后显示编辑专用按钮；修改前后的工作项目隔离，点击「保存」站内二选一：覆盖或另存为新的普通曲目，支持取消与放弃更改；离开未保存项目时拦截。
- 卷帘绘制使用 Canvas clipping region，音符在键名左侧边界被遮罩，不再穿模。
- 逐拍谱编辑区的两个按钮位于独立居中单元格，避免受当前事件文本宽度影响。
- 右下角在编辑模式替换舞台为「当前事件」编辑台，批量处理改为独立弹窗，歌曲信息改为右上角方形感叹号。

## 回归测试

- `tests/v04-interactions.cjs`：项目身份、重命名、复制删除、只读/编辑状态、撤销/重做、暂存、直接保存与另存、旧 `sky` 迁移、调性映射等 28 项断言通过。
- `tests/browser_v04.py`：实际 Chromium 交互，验证首页、弹窗、曲谱只读、32格/15键加载、右下工作台切换、调性与保存。
- `tests/audio_v04.py`：20份离线采样解码并发声，延音滑块改变混响节点，在线音源失败后自动回退。
- 已保留原始 v7 HTML 备份，并未覆盖。

## 已知限制

- 真实 Chromium 通过内存注入 HTML 进行浏览器交互测试，非 Windows 本机启动。在线 Yamaha C5 是否成功加载取决于用户网络。
- 音频自动识谱与视频逐格识谱仍属于实验版本，本轮未改变其准确率。
- 浏览器私密模式或禁用存储时，仅当前页面内可用；应及时导出 `.skymusic` 备份。
